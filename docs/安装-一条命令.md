## 🔴 装之前你需要知道的三件事

### 1. 服务**早就装好了**（我上轮说错��

```
/etc/systemd/system/omen-fand.service   10月11日 00:20
```

但它跑的是 **`/usr/local/bin/omen-control`（旧 debug 版，71 MB）**，
我这两轮的修复一条都没生效 —— 这就是为什么装了等于没装。

### 2. 服务现在是 `failed`（start-limit-hit）

```
01:19:22 Started → 跑6秒 → 收尾退出
01:19:29 Started → 跑0秒 → Stopping → 收尾退出
01:19:30 Started → 跑4秒 → 收尾退出
01:19:35 Failed with result 'start-limit-hit'
```

日志里明写 `systemd Stopping` —— 是外部反复 restart 它，不是自己崩的。
我已经关掉了那个抢风扇的进程，你跑完 install 会重新拉起。

### 3. 装完的验收

```bash
systemctl is-active omen-fand                    # 要 active
journalctl -u omen-fand -f                        # 另开一个窗口看
```

**看日志里的温度是不是平滑的** —— 新版应该长这样：
```
→ 写 25%（≈2533 RPM）  CPU 74°C / GPU 48°C（原始 60/48）
→ 写 25%（≈2533 RPM）  CPU 71°C / GPU 48°C（原始 64/48）   ← 真实温度与决策值分离
```
若是 `CPU 99°C（原始 99）` 这种，说明还是旧版。
